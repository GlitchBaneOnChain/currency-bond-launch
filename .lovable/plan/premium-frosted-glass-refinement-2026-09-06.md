# Premium frosted glass refinement

## Goal
Elevate Bankpad’s existing navy, gold, and blue experience with stronger glass depth, polished interaction, and clearer visual hierarchy across every screen.

## Changes
1. Refine the shared visual system with layered translucent surfaces, light-catching borders, deeper shadows, subtle grain, and improved background illumination.
2. Upgrade the navigation, buttons, controls, cards, and progress displays with tactile hover, focus, and press feedback.
3. Improve the homepage composition with a more immersive first view, elevated statistics, stronger section rhythm, and richer token presentation.
4. Apply the same premium glass treatment consistently to Launch, Explore, Dashboard, and token pages without changing their content or behavior.
5. Respect reduced motion preferences and confirm desktop and mobile layouts have no overlap or overflow.

## Technical details
Use existing semantic color variables and shared glass utilities. Remove manual browser prefixes so the production glass effect remains reliable. Keep all interactions lightweight and CSS driven.
